### 🟢 入门 · O(1) 最小值栈 {#easy}

- 适合：学习 Vec 和泛型
- 时间：约 10–15 分钟
- 题目：只用标准库，写一个栈，`push` / `pop` / `top` 之外，还要能 O(1) 拿到当前栈里的最小值

```rust
pub struct MinStack<T: Ord + Clone> { /* 你来定 */ }

impl<T: Ord + Clone> MinStack<T> {
    pub fn new() -> Self;
    pub fn push(&mut self, value: T);
    pub fn pop(&mut self) -> Option<T>;
    pub fn top(&self) -> Option<&T>;
    pub fn get_min(&self) -> Option<&T>;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
}
```

要求：
- 全部操作 O(1)：`get_min` 不能每次扫描整个栈。
- 栈空时 `pop` / `top` / `get_min` 都返回 `None`。
- 最小值可以重复出现：把唯一的最小值 `pop` 掉之后，`get_min` 要回到次小值，不能还报那个已经被弹掉的值。

通过标准：

```rust
// 1. 基本操作 + 最小值
let mut s = MinStack::new();
s.push(3); s.push(5);
assert_eq!(s.top(), Some(&5));
assert_eq!(s.get_min(), Some(&3));

// 2. 入栈更小的值，最小值跟着变
let mut s = MinStack::new();
s.push(5); s.push(2); s.push(4);
assert_eq!(s.get_min(), Some(&2));
s.push(1);
assert_eq!(s.get_min(), Some(&1));

// 3. 弹掉最小值后，最小值回到次小值
let mut s = MinStack::new();
s.push(3); s.push(1); s.push(2);
assert_eq!(s.pop(), Some(2));
assert_eq!(s.get_min(), Some(&1));
assert_eq!(s.pop(), Some(1));
assert_eq!(s.get_min(), Some(&3));

// 4. 最小值重复出现时，弹掉一个还剩一个
let mut s = MinStack::new();
s.push(2); s.push(2); s.push(1); s.push(1);
assert_eq!(s.pop(), Some(1));
assert_eq!(s.get_min(), Some(&1));
assert_eq!(s.pop(), Some(1));
assert_eq!(s.get_min(), Some(&2));

// 5. 空栈三件套都是 None
let mut s: MinStack<i32> = MinStack::new();
assert_eq!(s.pop(), None);
assert_eq!(s.top(), None);
assert_eq!(s.get_min(), None);

// 6. 递减入栈 9..0，最小值是 0，再按 0..9 的顺序弹出
// 7. String 做值也能用（"banana" / "apple" / "cherry"，最小是 "apple"）
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：只存一个 `min` 变量会在最小值被弹掉后丢信息——想想每个元素入栈时能顺手多记点什么，让 `pop` 之后最小值自己“回来”。</small>
</details>

### 🟡 进阶 · 手写迷你 HashMap（开放寻址） {#medium}

- 适合：理解哈希表内部结构
- 时间：约 45–60 分钟
- 题目：只用标准库，手写一个泛型哈希表：key 哈希到桶里，冲突用线性探测解决，删掉的槽位留墓碑，装满了就扩容重哈希。`insert` / `get` / `remove` 均摊 O(1)

```rust
pub struct MyHashMap<K, V> { /* 你来定 */ }

impl<K, V> MyHashMap<K, V>
where
    K: Eq + Hash,
{
    pub fn new() -> Self;
    pub fn insert(&mut self, key: K, value: V) -> Option<V>;
    pub fn get(&self, key: &K) -> Option<&V>;
    pub fn get_mut(&mut self, key: &K) -> Option<&mut V>;
    pub fn remove(&mut self, key: &K) -> Option<V>;
    pub fn contains_key(&self, key: &K) -> bool;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
}
```

要求：
- 哈希用 `std::collections::hash_map::DefaultHasher`（`DefaultHasher::new()` 是确定性哈希）：桶下标 = 哈希值 % 容量。
- 冲突用线性探测：桶被占就往下一个桶找，一圈找回来算满。
- 删除不能直接把槽位清空——要留墓碑（tombstone）：`get` 探测时遇到墓碑要跳过继续找，遇到空桶才能停；否则删掉的 key 后面的 key 就找不到了。
- `insert` 已存在的 key：原地替换 value，返回旧值，`len` 不变；新 key 插进第一个空桶，优先复用墓碑。
- 负载因子超过 0.7 就扩容：容量翻倍，只把还在的条目按新容量重新放桶，墓碑顺便清掉。墓碑太多时也要扩容——光看 `len` 会漏算探测链的长度。

通过标准：

```rust
// 1. 基本存取 + 覆盖返回旧值
let mut m = MyHashMap::new();
assert_eq!(m.insert("a", 1), None);
assert_eq!(m.insert("b", 2), None);
assert_eq!(m.get(&"a"), Some(&1));
assert_eq!(m.insert("a", 10), Some(1)); // 覆盖
assert_eq!(m.get(&"a"), Some(&10));
assert_eq!(m.len(), 2);

// 2. 查不到的 key
assert_eq!(m.get(&"z"), None);
assert!(!m.contains_key(&"z"));
assert_eq!(m.remove(&"z"), None);

// 3. 删除返回旧值，删后再查不到，len 缩小
let mut m = MyHashMap::new();
m.insert("x", 5); m.insert("y", 6);
assert_eq!(m.remove(&"x"), Some(5));
assert_eq!(m.get(&"x"), None);
assert_eq!(m.get(&"y"), Some(&6));
assert_eq!(m.len(), 1);

// 4. get_mut 原地改值
let mut m = MyHashMap::new();
m.insert("n", 1);
*m.get_mut(&"n").unwrap() += 41;
assert_eq!(m.get(&"n"), Some(&42));

// 5. 墓碑不能断探测链：插 0..40，删掉其中一半，再插 40..60，
//    剩下的奇数 key 和新 key 必须全都找得到，len 为 40。

// 6. 扩容：插 200 个 key 后 len 为 200，200 个全都查得到。

// 7. String 做 key、删后重插同一个 key 能成功；
//    插 500 个 key 后，查 500..600 的 key 全部返回 None。
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：难点就两处——一是删除为什么不能直接清空槽位（想想探测什么时候停），二是扩容的触发条件为什么不能只看 `len`（墓碑占着桶，探测照样要走过它们）。`DefaultHasher` + `Hash` trait 就能算桶，不用自己写哈希函数。</small>
</details>

### 🔴 挑战 · 手写跳表 SkipList {#hard}

- 适合：练习概率型数据结构和多层链表
- 时间：约 45–60 分钟
- 题目：只用标准库，手写一个跳表：key 有序，`insert` / `get` / `remove` 期望 O(log n)， 还能按升序列出全部 key

```rust
pub struct SkipList<K, V> { /* 你来定 */ }

impl<K: Ord, V> SkipList<K, V> {
    pub fn new() -> Self;
    pub fn insert(&mut self, key: K, value: V) -> Option<V>;
    pub fn get(&self, key: &K) -> Option<&V>;
    pub fn remove(&mut self, key: &K) -> Option<V>;
    pub fn contains_key(&self, key: &K) -> bool;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    pub fn keys(&self) -> Vec<&K>; // 升序
}
```

要求：
- 多层链表：每个节点随机分到 1 到 16 层，每上一层出现的概率是 1/2；0 层串起全部节点，越往上越稀疏，查找从顶层往下跳。
- 不用 `rand` crate：自己写一个简单的 xorshift 随机数，种子固定也可。
- `insert` 已存在的 key：原地替换 value，返回旧值，`len` 不变。
- `remove` 后各层的链接不能断：删掉的节点后面的 key 仍能查到。
- 不用 unsafe：节点用索引式 `Vec` 或 `Rc` 存都行。

通过标准：

```rust
// 1. 基本存取 + 覆盖返回旧值
let mut m = SkipList::new();
assert_eq!(m.insert(3, "three"), None);
assert_eq!(m.insert(1, "one"), None);
assert_eq!(m.get(&3), Some(&"three"));
assert_eq!(m.insert(3, "THREE"), Some("three"));
assert_eq!(m.len(), 2);

// 2. 查不到 / 删不到的 key
let mut m = SkipList::new();
m.insert(10, 'a'); m.insert(20, 'b');
assert_eq!(m.remove(&99), None);
assert_eq!(m.remove(&10), Some('a'));
assert_eq!(m.get(&10), None);

// 3. 插 0..200，200 个全都查得到，len 为 200
// 4. keys() 严格升序
// 5. 删掉 0..100 里的偶数，剩下的奇数全都找得到，偶数全都找不到，len 为 50，keys() 就是奇数列
// 6. 删掉再重插同一个 key：不再是覆盖，insert 返回 None，值是新的
// 7. String 做 key：apple/banana/cherry 有序，删掉 banana 后 keys() 剩 apple、cherry
// 8. 插 1000 个 key，删掉其中每 3 个里的 1 个，剩下的全都找得到，keys() 仍严格升序且长度等于 len
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：难点不在随机层数，在 insert/remove 之前要先把每一层的前驱都记下来，再逐层接线——先写一个“找每一层前驱”的辅助函数，让 insert 和 remove 共用它；删节点时先断链接再取值，别急着把节点从 Vec 里挪走（下标会指错）。</small>
</details>

### 🟢 入门 · 游程编码

**参考解析**： 核心是按 `char` 一遍扫过去数连续相同字符——当前字符与前一个不同就结算一次，次数永远写出（哪怕是 1），空串直接返回空串。

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
pub fn run_length_encode(s: &str) -> String {
    let mut out = String::new();
    let mut chars = s.chars().peekable();
    while let Some(c) = chars.next() {
        let mut count = 1usize;
        while chars.peek() == Some(&c) {
            chars.next();
            count += 1;
        }
        out.push(c);
        out.push_str(&count.to_string());
    }
    out
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn encode_works() {
        assert_eq!(run_length_encode(""), "");
        assert_eq!(run_length_encode("abc"), "a1b1c1");
        assert_eq!(run_length_encode("aaabbc"), "a3b2c1");
        assert_eq!(run_length_encode("aabbaa"), "a2b2a2");
        assert_eq!(run_length_encode("aaaaaaaaaaaa"), "a12"); // 12 个 a，次数两位数
        assert_eq!(run_length_encode("ééé"), "é3"); // 多字节字符按 char 数
        assert_eq!(run_length_encode("  "), " 2"); // 空格也是普通字符
    }
}
```

### 🟡 进阶 · 手写迷你 Arc（带 Weak）（7 个测试）

**参考解析**： 核心是强弱两套计数加一个隐式 weak——值析构与分配释放是两件分开的事，值在最后一个 strong 释放时析构一次，分配等到 weak 也归零才释放；`upgrade` 必须用 CAS 循环，先判 0 再原子地 +1，不能先判后加。

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
use std::cell::UnsafeCell;
use std::mem::ManuallyDrop;
use std::ops::Deref;
use std::ptr::NonNull;
use std::sync::atomic::{AtomicUsize, Ordering, fence};

struct ArcInner<T> {
    strong: AtomicUsize,
    weak: AtomicUsize,
    data: UnsafeCell<ManuallyDrop<T>>,
}

pub struct MyArc<T> {
    ptr: NonNull<ArcInner<T>>,
}

pub struct MyWeak<T> {
    ptr: NonNull<ArcInner<T>>,
}

unsafe impl<T: Send + Sync> Send for MyArc<T> {}
unsafe impl<T: Send + Sync> Sync for MyArc<T> {}
unsafe impl<T: Send + Sync> Send for MyWeak<T> {}
unsafe impl<T: Send + Sync> Sync for MyWeak<T> {}

fn release_weak<T>(inner: &ArcInner<T>) {
    if inner.weak.fetch_sub(1, Ordering::Release) == 1 {
        fence(Ordering::Acquire);
        unsafe {
            drop(Box::from_raw(inner as *const ArcInner<T> as *mut ArcInner<T>));
        }
    }
}

impl<T> MyArc<T> {
    pub fn new(value: T) -> Self {
        let inner = Box::new(ArcInner {
            strong: AtomicUsize::new(1),
            weak: AtomicUsize::new(1),
            data: UnsafeCell::new(ManuallyDrop::new(value)),
        });
        MyArc {
            ptr: NonNull::from(Box::leak(inner)),
        }
    }

    fn inner(&self) -> &ArcInner<T> {
        unsafe { self.ptr.as_ref() }
    }

    pub fn strong_count(&self) -> usize {
        self.inner().strong.load(Ordering::SeqCst)
    }

    pub fn weak_count(&self) -> usize {
        self.inner().weak.load(Ordering::SeqCst)
    }

    pub fn downgrade(&self) -> MyWeak<T> {
        self.inner().weak.fetch_add(1, Ordering::Relaxed);
        MyWeak { ptr: self.ptr }
    }
}

impl<T> Clone for MyArc<T> {
    fn clone(&self) -> Self {
        self.inner().strong.fetch_add(1, Ordering::Relaxed);
        MyArc { ptr: self.ptr }
    }
}

impl<T> Deref for MyArc<T> {
    type Target = T;

    fn deref(&self) -> &T {
        unsafe { &*self.inner().data.get() }
    }
}

impl<T> Drop for MyArc<T> {
    fn drop(&mut self) {
        let inner = self.inner();
        if inner.strong.fetch_sub(1, Ordering::Release) == 1 {
            fence(Ordering::Acquire);
            // 最后一个 strong：先析构值，再释放 strong 持有的隐式 weak。
            unsafe {
                ManuallyDrop::drop(&mut *inner.data.get());
            }
            release_weak(inner);
        }
    }
}

impl<T> MyWeak<T> {
    fn inner(&self) -> &ArcInner<T> {
        unsafe { self.ptr.as_ref() }
    }

    pub fn upgrade(&self) -> Option<MyArc<T>> {
        let inner = self.inner();
        let mut cur = inner.strong.load(Ordering::Relaxed);
        loop {
            if cur == 0 {
                return None;
            }
            match inner
                .strong
                .compare_exchange_weak(cur, cur + 1, Ordering::AcqRel, Ordering::Relaxed)
            {
                Ok(_) => return Some(MyArc { ptr: self.ptr }),
                Err(next) => cur = next,
            }
        }
    }

    pub fn strong_count(&self) -> usize {
        self.inner().strong.load(Ordering::SeqCst)
    }

    pub fn weak_count(&self) -> usize {
        self.inner().weak.load(Ordering::SeqCst)
    }
}

impl<T> Clone for MyWeak<T> {
    fn clone(&self) -> Self {
        self.inner().weak.fetch_add(1, Ordering::Relaxed);
        MyWeak { ptr: self.ptr }
    }
}

impl<T> Drop for MyWeak<T> {
    fn drop(&mut self) {
        release_weak(self.inner());
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::sync::atomic::AtomicUsize;
    use std::thread;

    static DROPPED: AtomicUsize = AtomicUsize::new(0);

    struct Probe;
    impl Drop for Probe {
        fn drop(&mut self) {
            DROPPED.fetch_add(1, Ordering::SeqCst);
        }
    }

    #[test]
    fn clone_shares_and_counts() {
        let a = MyArc::new(vec![1, 2, 3]);
        assert_eq!(a.strong_count(), 1);
        assert_eq!(a.weak_count(), 1); // 只有 strong 持有的隐式 weak
        let b = a.clone();
        assert_eq!(a.strong_count(), 2);
        assert_eq!(b.len(), 3);
        drop(b);
        assert_eq!(a.strong_count(), 1);
    }

    #[test]
    fn shared_across_threads() {
        let a = MyArc::new(vec![10, 20, 30]);
        let mut handles = Vec::new();
        for _ in 0..4 {
            let c = a.clone();
            handles.push(thread::spawn(move || c.iter().sum::<i32>()));
        }
        let mut total = 0;
        for h in handles {
            total += h.join().unwrap();
        }
        assert_eq!(total, 4 * 60);
        assert_eq!(a.strong_count(), 1);
    }

    #[test]
    fn downgrade_upgrade_while_alive() {
        let a = MyArc::new(42);
        let w = a.downgrade();
        assert_eq!(w.weak_count(), 2); // 隐式 weak + 这一个
        assert_eq!(w.strong_count(), 1);
        let up = w.upgrade().expect("strong 还活着，upgrade 必须成功");
        assert_eq!(*up, 42);
        assert_eq!(a.strong_count(), 2);
    }

    #[test]
    fn upgrade_fails_after_last_strong_dropped() {
        let a = MyArc::new(7);
        let w = a.downgrade();
        drop(a);
        assert!(w.upgrade().is_none());
        assert_eq!(w.strong_count(), 0);
    }

    #[test]
    fn value_dropped_once_when_last_strong_drops_even_with_weak_alive() {
        DROPPED.store(0, Ordering::SeqCst);
        let a = MyArc::new(Probe);
        let w = a.downgrade();
        assert_eq!(DROPPED.load(Ordering::SeqCst), 0);
        drop(a);
        assert_eq!(DROPPED.load(Ordering::SeqCst), 1, "值只析构一次");
        assert!(w.upgrade().is_none());
        drop(w);
        assert_eq!(DROPPED.load(Ordering::SeqCst), 1, "weak 释放不应再析构值");
    }

    #[test]
    fn weak_clone_and_drop_counts() {
        let a = MyArc::new(1);
        let w1 = a.downgrade();
        let w2 = w1.clone();
        assert_eq!(a.weak_count(), 3);
        drop(w2);
        assert_eq!(a.weak_count(), 2);
        drop(w1);
        assert_eq!(a.weak_count(), 1);
    }

    #[test]
    fn upgrade_increments_strong_and_keeps_value_alive() {
        let a = MyArc::new(String::from("hi"));
        let w = a.downgrade();
        drop(a);
        let up = w.upgrade();
        assert!(up.is_none(), "strong 已归零，不能复活");
        // 反向：strong 还在时 upgrade 拿到的 Arc 能独立持有值
        let a2 = MyArc::new(String::from("hi"));
        let w2 = a2.downgrade();
        let up2 = w2.upgrade().unwrap();
        drop(a2);
        assert_eq!(*up2, "hi");
        assert_eq!(up2.strong_count(), 1);
    }
}
```

### 🔴 挑战 · Treiber 无锁栈（参考解，4 个测试全过）

**参考解析**： 核心是头指针加 CAS 循环——`push` 把新节点挂到旧头上再 CAS 抢头，`pop` 读头、取 next、CAS 抢头，失败就拿回最新头重试；ABA 是教学简化，工业实现要配 hazard pointer 或 epoch 回收。

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
use std::ptr;
use std::sync::atomic::{AtomicPtr, Ordering};

struct Node<T> {
    value: T,
    next: *mut Node<T>,
}

pub struct TreiberStack<T> {
    head: AtomicPtr<Node<T>>,
}

// SAFETY: 栈内节点的访问全部经过 head 的原子 CAS 协议，
// T: Send 保证值可以跨线程移动所有权。
unsafe impl<T: Send> Send for TreiberStack<T> {}
unsafe impl<T: Send> Sync for TreiberStack<T> {}

impl<T> TreiberStack<T> {
    pub fn new() -> Self {
        TreiberStack {
            head: AtomicPtr::new(ptr::null_mut()),
        }
    }

    pub fn push(&self, value: T) {
        let node = Box::into_raw(Box::new(Node {
            value,
            next: ptr::null_mut(),
        }));
        loop {
            let head = self.head.load(Ordering::Relaxed);
            // SAFETY: node 是刚分配的、尚未发布的节点，只有本线程能访问。
            unsafe { (*node).next = head };
            if self
                .head
                .compare_exchange_weak(head, node, Ordering::Release, Ordering::Relaxed)
                .is_ok()
            {
                break;
            }
        }
    }

    pub fn pop(&self) -> Option<T> {
        loop {
            let head = self.head.load(Ordering::Acquire);
            if head.is_null() {
                return None;
            }
            // SAFETY: head 是 load 到的当前头节点；读它的 next 字段。
            // （教学简化：这里正是 ABA 风险所在，见文件头注释。）
            let next = unsafe { (*head).next };
            if self
                .head
                .compare_exchange_weak(head, next, Ordering::Acquire, Ordering::Relaxed)
                .is_ok()
            {
                // SAFETY: CAS 成功说明我们独占了这个节点，可以收回成 Box。
                let node = unsafe { Box::from_raw(head) };
                return Some(node.value);
            }
        }
    }

    pub fn is_empty(&self) -> bool {
        self.head.load(Ordering::Relaxed).is_null()
    }
}

impl<T> Drop for TreiberStack<T> {
    fn drop(&mut self) {
        // 独占 &mut 时不会再有并发访问，逐个弹出丢弃即可。
        while self.pop().is_some() {}
    }
}
```
