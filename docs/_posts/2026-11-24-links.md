### 🟢 入门 · 合并两个已排序切片 {#easy}

- 适合：理解 Vec 和切片
- 时间：约 15 分钟
- 题目：两个切片都已按升序排好，合并成一个新的升序 `Vec`，重复元素保留：

```rust
fn merge_sorted(a: &[i32], b: &[i32]) -> Vec<i32>
```

通过标准：

```rust
assert_eq!(merge_sorted(&[1, 3, 5], &[2, 4, 6]), vec![1, 2, 3, 4, 5, 6]);
assert_eq!(merge_sorted(&[], &[1]), vec![1]);
assert_eq!(merge_sorted(&[1, 2], &[]), vec![1, 2]);
assert_eq!(merge_sorted(&[1, 1, 3], &[1, 2]), vec![1, 1, 1, 2, 3]);
assert_eq!(merge_sorted(&[], &[]), Vec::<i32>::new());
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：双指针各指一个切片，每次把更小的那个放进结果；一个走完后，把另一个剩下的整段接上。先 `Vec::with_capacity(a.len() + b.len())` 预分配，省去反复扩容。</small>
</details>

### 🟡 进阶 · 手写迷你线程池 ThreadPool {#medium}

- 适合：练习并发原语和资源收尾
- 时间：约 45–60 分钟
- 题目：只用标准库，手写一个固定大小的线程池

```rust
pub struct ThreadPool { /* 你来定 */ }

impl ThreadPool {
    /// 创建 size 个工作线程；size 为 0 时 panic。
    pub fn new(size: usize) -> Self;

    /// 提交一个任务，在某个工作线程上执行一次。
    pub fn execute<F>(&self, f: F)
    where
        F: FnOnce() + Send + 'static;
}

// Drop 的语义也是题目的一部分：
// 不再接受新任务，已提交的任务全部执行完，
// 所有工作线程干净退出——不能死锁，也不能丢任务。
```

要求：
- 任务分发只用 `std::sync::mpsc` 通道；`Receiver` 要被多个工作线程共享，用 `Arc<Mutex<Receiver>>`。
- 任务在内部擦除成 `Box<dyn FnOnce() + Send + 'static>` 再进通道。
- 工作线程的循环：上锁 → `recv` 拿一个任务 → 放锁 → 执行；通道关闭且排空后 `recv` 返回 `Err`，线程退出。
- `Drop` 的顺序：先丢掉 `Sender` 关通道，再逐个 `join` 工作线程的句柄（句柄用 `Option` 包着 `take` 出来）。顺序反了会死锁或提前退出丢任务。

通过标准：

```rust
use std::sync::{mpsc, Arc};
use std::sync::atomic::{AtomicUsize, Ordering};
use std::time::Duration;

// 1. size 为 0 必须 panic
// （用 #[should_panic] 的测试单独验证 ThreadPool::new(0)）

// 2. 提交的任务会被执行
let pool = ThreadPool::new(2);
let (tx, rx) = mpsc::channel();
pool.execute(move || { tx.send(42).unwrap(); });
assert_eq!(rx.recv().unwrap(), 42);

// 3. 任务跑在工作线程上，不是提交它的线程
let pool = ThreadPool::new(1);
let main_id = std::thread::current().id();
let (tx, rx) = mpsc::channel();
pool.execute(move || { tx.send(std::thread::current().id()).unwrap(); });
assert_ne!(rx.recv().unwrap(), main_id);

// 4. drop 会等队列里的任务全做完
let counter = Arc::new(AtomicUsize::new(0));
{
    let pool = ThreadPool::new(4);
    for _ in 0..20 {
        let c = Arc::clone(&counter);
        pool.execute(move || {
            std::thread::sleep(Duration::from_millis(5));
            c.fetch_add(1, Ordering::SeqCst);
        });
    }
} // pool 在这里 drop
assert_eq!(counter.load(Ordering::SeqCst), 20);

// 5. 大量任务一个不丢
let counter = Arc::new(AtomicUsize::new(0));
let pool = ThreadPool::new(4);
for _ in 0..100 {
    let c = Arc::clone(&counter);
    pool.execute(move || { c.fetch_add(1, Ordering::SeqCst); });
}
drop(pool);
assert_eq!(counter.load(Ordering::SeqCst), 100);
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：最容易卡住的是 `Drop` 的死锁——如果先 `join` 再关通道，线程全堵在 `recv` 上永远等不到任务；如果关了通道但不 `join`，`drop` 返回时任务可能还没跑完。另一个小坑：`Mutex` 的锁只在 `recv` 期间持有，拿到任务先放锁再执行，不然整个池子退化成单线程。</small>
</details>

### 🔴 挑战 · 手写迷你 MyVec<T> {#hard}

- 适合：练习 unsafe、 裸指针与内存布局
- 时间：约 30–45 分钟
- 题目：只用标准库，用 unsafe 裸指针和 `std::alloc` 实现一个支持 push/pop、扩容与正确 Drop 的迷你 Vec：

```rust
use std::alloc::{alloc, dealloc, handle_alloc_error, realloc, Layout};
use std::ptr::{self, NonNull};

pub struct MyVec<T> {
    // 你来定：裸指针 + 长度 + 容量
}

impl<T> MyVec<T> {
    pub fn new() -> Self;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    pub fn capacity(&self) -> usize;
    pub fn push(&mut self, value: T);
    pub fn pop(&mut self) -> Option<T>;
    pub fn get(&self, index: usize) -> Option<&T>;
    pub fn get_mut(&mut self, index: usize) -> Option<&mut T>;
}

impl<T> Deref for MyVec<T> { type Target = [T]; }      // 让 v[0]、v.iter() 能用
impl<T> DerefMut for MyVec<T> {}
impl<T> Drop for MyVec<T> {}
```

要求：
- `push` 满了要扩容（初始 4，之后翻倍），扩容时已存的元素必须原样保留。
- `pop` 把元素所有权交出去，之后 `Drop` 不能再析构它（否则 double free）。
- `Drop` 时先析构每个还活着的元素，再释放整块内存；空的 MyVec 不分配也不释放。
- ZST（零大小类型）不作要求。

通过标准：

```rust
// 1. 基本 push / pop
let mut v = MyVec::new();
assert!(v.is_empty());
assert_eq!(v.pop(), None);
v.push(1); v.push(2); v.push(3);
assert_eq!(v.len(), 3);
assert_eq!(v.pop(), Some(3));
assert_eq!(v.pop(), Some(2));
assert_eq!(v.pop(), Some(1));
assert_eq!(v.pop(), None);

// 2. 扩容到 100 个元素
let mut v = MyVec::new();
for i in 0..100 { v.push(i); }
assert_eq!(v.len(), 100);
assert!(v.capacity() >= 100);
for i in 0..100 { assert_eq!(v.get(i), Some(&i)); }
assert_eq!(v.get(100), None);

// 3. 下标与迭代（靠 Deref）
let mut v = MyVec::new();
v.push(10); v.push(20); v.push(30);
assert_eq!(v[1], 20);
assert_eq!(v.iter().sum::<i32>(), 60);
v[0] = 99;
assert_eq!(v[0], 99);
*v.get_mut(2).unwrap() = 7;
assert_eq!(v[2], 7);

// 4. Drop 只析构还活着的元素
use std::cell::Cell;
use std::rc::Rc;
struct Counted(Rc<Cell<usize>>);
impl Drop for Counted {
    fn drop(&mut self) { self.0.set(self.0.get() + 1); }
}
let counter = Rc::new(Cell::new(0));
{
    let mut v = MyVec::new();
    v.push(Counted(counter.clone()));
    v.push(Counted(counter.clone()));
    v.push(Counted(counter.clone()));
    assert_eq!(v.pop().is_some(), true);
    drop(v.pop()); // 显式 drop，计数 +1
    assert_eq!(counter.get(), 2);
} // 剩余 1 个随 MyVec 一起 drop
assert_eq!(counter.get(), 3);

// 5. 能存 String 这种带堆内存的类型
let mut v = MyVec::new();
v.push(String::from("hello"));
v.push(String::from("rust"));
assert_eq!(v.len(), 2);
assert_eq!(v[0], "hello");
assert_eq!(v.pop().unwrap(), "rust");
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：分配用 `Layout::array::<T>(cap)`；`realloc` 扩容时要传**旧** Layout；`push` 用 `ptr::write` 把值写进去（不能用 `*ptr = value`，那样会先读出未初始化的旧值再 drop）；`pop` 用 `ptr::read` 把值搬出来；容量为 0 时用 `NonNull::dangling()`，`dealloc` 只在 `cap != 0` 时做。</small>
</details>

### 🟢 入门 · 出现次数最多的元素

**参考解析**: HashMap 计数，再用 `max_by` 按“次数降序、值升序”取最大，并列取最小。

<details markdown="1">
<summary>点击查看代码</summary>

```rust
use std::collections::HashMap;

fn most_frequent(nums: &[i32]) -> Option<i32> {
    let mut counts: HashMap<i32, usize> = HashMap::new();
    for &n in nums {
        *counts.entry(n).or_insert(0) += 1;
    }
    counts
        .into_iter()
        .max_by(|a, b| a.1.cmp(&b.1).then(b.0.cmp(&a.0)))
        .map(|(n, _)| n)
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn basic() {
        assert_eq!(most_frequent(&[1, 2, 2, 3, 3, 3]), Some(3));
        assert_eq!(most_frequent(&[2, 1, 2, 1]), Some(1)); // 并列取最小
        assert_eq!(most_frequent(&[]), None);
        assert_eq!(most_frequent(&[5]), Some(5));
        assert_eq!(most_frequent(&[-1, -1, 2]), Some(-1));
    }
}
```

### 🟡 进阶 · 手写迷你 anyhow-lite 错误处理库

**参考解析**: `Error` 存消息 + `Box<dyn StdError + Send + Sync + 'static>` 做 source 链；`Context` 对所有 `Result<T, E: StdError>` 做 blanket 实现；`io::Error`、`ParseIntError` 用 `?` 转进来靠单独的 `From`；`with_context` 闭包只在 `Err` 时调用，是惰性的；`chain()` 从外到内逐层列出 source 链。

<details markdown="1">
<summary>点击查看代码</summary>

```rust
use std::error::Error as StdError;
use std::fmt;

pub struct Error {
    msg: String,
    source: Option<Box<dyn StdError + Send + Sync + 'static>>,
}

impl Error {
    pub fn new(msg: impl Into<String>) -> Self {
        Error { msg: msg.into(), source: None }
    }

    pub fn with_source<E>(msg: impl Into<String>, source: E) -> Self
    where
        E: StdError + Send + Sync + 'static,
    {
        Error { msg: msg.into(), source: Some(Box::new(source)) }
    }

    pub fn msg(&self) -> &str {
        &self.msg
    }

    pub fn chain(&self) -> Chain<'_> {
        Chain { next: Some(self) }
    }
}

impl fmt::Display for Error {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}", self.msg)
    }
}

impl fmt::Debug for Error {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}", self.msg)?;
        if let Some(src) = &self.source {
            write!(f, ": {src:?}")?;
        }
        Ok(())
    }
}

impl StdError for Error {
    fn source(&self) -> Option<&(dyn StdError + 'static)> {
        self.source.as_deref().map(|e| e as &(dyn StdError + 'static))
    }
}

impl From<std::io::Error> for Error {
    fn from(e: std::io::Error) -> Self {
        Error::with_source(e.to_string(), e)
    }
}

impl From<std::num::ParseIntError> for Error {
    fn from(e: std::num::ParseIntError) -> Self {
        Error::with_source(e.to_string(), e)
    }
}

pub type Result<T> = std::result::Result<T, Error>;

pub struct Chain<'a> {
    next: Option<&'a (dyn StdError + 'static)>,
}

impl<'a> Iterator for Chain<'a> {
    type Item = &'a (dyn StdError + 'static);

    fn next(&mut self) -> Option<Self::Item> {
        let cur = self.next?;
        self.next = cur.source();
        Some(cur)
    }
}

pub trait Context<T, E> {
    fn context<C>(self, context: C) -> Result<T>
    where
        C: fmt::Display + Send + Sync + 'static;

    fn with_context<C, F>(self, f: F) -> Result<T>
    where
        C: fmt::Display + Send + Sync + 'static,
        F: FnOnce() -> C;
}

impl<T, E> Context<T, E> for std::result::Result<T, E>
where
    E: StdError + Send + Sync + 'static,
{
    fn context<C>(self, context: C) -> Result<T>
    where
        C: fmt::Display + Send + Sync + 'static,
    {
        self.map_err(|e| Error::with_source(context.to_string(), e))
    }

    fn with_context<C, F>(self, f: F) -> Result<T>
    where
        C: fmt::Display + Send + Sync + 'static,
        F: FnOnce() -> C,
    {
        self.map_err(|e| Error::with_source(f().to_string(), e))
    }
}

#[macro_export]
macro_rules! ensure {
    ($cond:expr, $msg:expr) => {
        if !$cond {
            return Err($crate::Error::new($msg));
        }
    };
    ($cond:expr, $fmt:expr, $($arg:tt)*) => {
        if !$cond {
            return Err($crate::Error::new(format!($fmt, $($arg)*)));
        }
    };
}
```

### 🔴 挑战 · 手写类型安全的 Arena 分配器

**参考解析**: 分块存储，每块 `Box<[MaybeUninit<T>; 32]>`，块一旦分配就不再移动；`alloc` 只有 `&self`，可变状态包在 `UnsafeCell` 里；每个槽位只 `ptr::write` 一次，`Drop` 只析构写过的槽位。sound 的理由：每个槽位只写一次、地址永不移动（块是 Box，Vec 扩容只搬 Box 不搬元素），每次 `alloc` 返回的 `&mut` 指向互不重叠的槽位；槽位在 arena 活着期间不单独释放。

<details markdown="1">
<summary>点击查看代码</summary>

```rust
use std::cell::UnsafeCell;
use std::mem::MaybeUninit;
use std::ptr;

const BLOCK: usize = 32;

struct Block<T> {
    items: Box<[MaybeUninit<T>; BLOCK]>,
    len: usize, // 本块已初始化的元素个数
}

pub struct Arena<T> {
    blocks: UnsafeCell<Vec<Block<T>>>,
}

impl<T> Arena<T> {
    pub fn new() -> Self {
        Arena { blocks: UnsafeCell::new(Vec::new()) }
    }

    pub fn alloc(&self, value: T) -> &mut T {
        unsafe {
            let blocks = &mut *self.blocks.get();
            if blocks.is_empty() || blocks.last().unwrap().len == BLOCK {
                blocks.push(Block { items: Box::new(std::array::from_fn(|_| MaybeUninit::uninit())), len: 0 });
            }
            let block = blocks.last_mut().unwrap();
            let idx = block.len;
            block.items[idx].write(value);
            block.len += 1;
            &mut *block.items[idx].as_mut_ptr()
        }
    }

    pub fn get(&self, index: usize) -> Option<&T> {
        unsafe {
            let blocks = &*self.blocks.get();
            let (b, off) = (index / BLOCK, index % BLOCK);
            let block = blocks.get(b)?;
            if off >= block.len {
                return None;
            }
            Some(&*block.items[off].as_ptr())
        }
    }

    pub fn len(&self) -> usize {
        unsafe { (&*self.blocks.get()).iter().map(|b| b.len).sum() }
    }

    pub fn is_empty(&self) -> bool {
        self.len() == 0
    }
}

impl<T> Drop for Arena<T> {
    fn drop(&mut self) {
        unsafe {
            let blocks = &mut *self.blocks.get();
            for block in blocks.iter_mut() {
                for slot in block.items.iter_mut().take(block.len) {
                    ptr::drop_in_place(slot.as_mut_ptr());
                }
            }
        }
    }
}
```

</details>
