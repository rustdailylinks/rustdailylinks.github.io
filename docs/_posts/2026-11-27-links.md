### 🟢 入门 · 游程编码 {#easy}

- 适合：理解字符串和迭代器
- 时间：约 10–15 分钟
- 题目：只用标准库，把字符串做游程编码（run-length encoding）：连续重复的字符压成「字符 + 次数」，次数永远写出（哪怕是 1），次数可以是多位数

```rust
pub fn run_length_encode(s: &str) -> String;
```

通过标准：

```rust
assert_eq!(run_length_encode(""), "");
assert_eq!(run_length_encode("abc"), "a1b1c1");
assert_eq!(run_length_encode("aaabbc"), "a3b2c1");
assert_eq!(run_length_encode("aabbaa"), "a2b2a2");
assert_eq!(run_length_encode("aaaaaaaaaaaa"), "a12"); // 12 个 a
assert_eq!(run_length_encode("ééé"), "é3");
assert_eq!(run_length_encode("  "), " 2");
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：按 `char` 数，不要按字节切。遍历时记住「当前字符 + 已连续出现几次」，字符一变就把上一组写进结果。`chars().peekable()` 能偷看下一个字符是不是同一个。</small>
</details>

### 🟡 进阶 · 手写迷你 Arc（带 Weak） {#medium}

- 适合：学习原子计数和引用计数并发安全
- 时间：约 45–60 分钟
- 题目：只用标准库，手写一个线程安全的迷你版 `Arc`，再加一个 `Weak`：多线程共享同一份值，值在最后一个强引用释放时析构一次，弱引用能判断值还在不在

```rust
pub struct MyArc<T> { /* 你来定 */ }
pub struct MyWeak<T> { /* 你来定 */ }

impl<T> MyArc<T> {
    pub fn new(value: T) -> Self;
    pub fn strong_count(&self) -> usize;
    pub fn weak_count(&self) -> usize;
    pub fn downgrade(&self) -> MyWeak<T>;
}

impl<T> MyWeak<T> {
    /// 强引用还活着时返回 Some，拿回一个强引用；都释放后返回 None。
    pub fn upgrade(&self) -> Option<MyArc<T>>;
    pub fn strong_count(&self) -> usize;
    pub fn weak_count(&self) -> usize;
}

// MyArc 实现 Clone + Deref；MyWeak 实现 Clone。
// MyArc<T> 在 T: Send + Sync 时是 Send + Sync。
```

要求：
- 值存在堆上（`Box`），计数用 `AtomicUsize`：strong 从 1 起，weak 从 1 起——这 1 是 strong 持有的隐式 weak，只要还有 strong，内层分配就不能释放。
- 最后一个 strong 释放时：先析构值，再释放隐式 weak；weak 归零时释放整个分配。值恰好析构一次，哪怕还有 Weak 活着。
- `upgrade` 要用 CAS 循环：strong 为 0 返回 `None`，否则原子地 +1 再返回 `Some`，不能出现「判活着、随后被释放」的竞态。
- 内部可以 unsafe，但对外必须是 sound 的：只要安全代码按 API 用，就不能造出数据竞争或 use-after-free。

通过标准：

```rust
// 1. Clone 共享同一份值，计数对得上
let a = MyArc::new(vec![1, 2, 3]);
assert_eq!(a.strong_count(), 1);
assert_eq!(a.weak_count(), 1); // 只有 strong 持有的隐式 weak
let b = a.clone();
assert_eq!(a.strong_count(), 2);
assert_eq!(b.len(), 3);
drop(b);
assert_eq!(a.strong_count(), 1);

// 2. 多线程共享：4 个线程各 clone 一份读值
let a = MyArc::new(vec![10, 20, 30]);
let mut handles = Vec::new();
for _ in 0..4 {
    let c = a.clone();
    handles.push(thread::spawn(move || c.iter().sum::<i32>()));
}
let mut total = 0;
for h in handles { total += h.join().unwrap(); }
assert_eq!(total, 4 * 60);
assert_eq!(a.strong_count(), 1);

// 3. strong 活着时 upgrade 成功
let a = MyArc::new(42);
let w = a.downgrade();
assert_eq!(w.weak_count(), 2);
let up = w.upgrade().expect("strong 还活着，upgrade 必须成功");
assert_eq!(*up, 42);

// 4. 最后一个 strong 释放后 upgrade 返回 None
let a = MyArc::new(7);
let w = a.downgrade();
drop(a);
assert!(w.upgrade().is_none());
assert_eq!(w.strong_count(), 0);

// 5. 值恰好析构一次（用带 Drop 计数器的探针测）：
//    strong 释放后计数为 1，再释放 Weak 也不应变成 2。

// 6. Weak 的 Clone / Drop 让 weak_count 正确增减
let a = MyArc::new(1);
let w1 = a.downgrade();
let w2 = w1.clone();
assert_eq!(a.weak_count(), 3);
drop(w2);
assert_eq!(a.weak_count(), 2);

// 7. upgrade 拿到的 Arc 能独立持有值
let a = MyArc::new(String::from("hi"));
let w = a.downgrade();
let up = w.upgrade().unwrap();
drop(a);
assert_eq!(*up, "hi");
assert_eq!(up.strong_count(), 1);
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：难点不在 clone，在两处释放顺序——值析构与分配释放是两件分开的事，中间隔着 weak 计数；另一处是 `upgrade` 的 CAS 循环：先 load 再 CAS，失败要拿回最新值重试，不能直接 `fetch_add`。`ManuallyDrop` 能让你手动控制值的析构时机，`fence(Acquire)` 配 `fetch_sub(Release)` 保证析构对其他线程可见。</small>
</details>

### 🔴 挑战 · Treiber 无锁栈 {#hard}

- 适合：练习原子操作和无锁数据结构
- 时间：约 45–60 分钟
- 题目：只用标准库，写一个无锁（lock-free）栈：头指针是一个 `AtomicPtr`，`push` / `pop` 全靠 CAS 循环抢头指针，全程不许用 `Mutex` / `RwLock`

```rust
pub struct TreiberStack<T> { /* 你来定 */ }

impl<T> TreiberStack<T> {
    pub fn new() -> Self;
    pub fn push(&self, value: T);
    pub fn pop(&self) -> Option<T>;
    pub fn is_empty(&self) -> bool;
}

// TreiberStack<T> 在 T: Send 时实现 Send + Sync。
```

要求：
- 节点用 `Box::into_raw` 分配成链表；`push` 先把新节点的 next 指向当前 head，再 CAS 把 head 换成新节点，失败重试；`pop` 先读 head 和它的 next，再 CAS 把 head 换成 next，成功后用 `Box::from_raw` 收回节点并返回值。
- `pop` 空栈返回 `None`，不许 panic。
- 栈 `Drop` 时把剩余节点全部弹出丢弃，每个值恰好析构一次。
- 内存序可以自己选，但要在注释里说清每个操作为什么用这个序。

通过标准：

```rust
// 1. 后进先出 + 空栈
let s = TreiberStack::new();
assert!(s.is_empty());
s.push(1); s.push(2); s.push(3);
assert_eq!(s.pop(), Some(3));
assert_eq!(s.pop(), Some(2));
assert_eq!(s.pop(), Some(1));
assert_eq!(s.pop(), None);

// 2. 交错 push / pop
let s = TreiberStack::new();
s.push("a"); s.push("b");
assert_eq!(s.pop(), Some("b"));
s.push("c");
assert_eq!(s.pop(), Some("c"));
assert_eq!(s.pop(), Some("a"));

// 3. 并发：8 个线程各 push 500 个互不相同的值（共 4000 个），
//    全部 join 后单线程排空，排序后应恰好是 0..4000，一个不多一个不少。

// 4. 值恰好析构一次：带 Drop 计数器的探针 push 100 个、pop 40 个丢弃，
//    计数器应为 40；再 drop 整个栈，应变为 100。
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：这道题藏着无锁编程最经典的坑——ABA：`pop` 读完 head 和 next 之后、CAS 之前，另一个线程可能把这个节点 pop 走、释放、又 push 回一个地址相同的新节点，你的 CAS 会误以为「什么都没变」。本题是教学实现，接受这个简化（工业级要配 hazard pointer 或 epoch 回收），但要在代码注释里把 ABA 写清楚。另两个小坑：`compare_exchange_weak` 允许伪失败，循环里用它更便宜；`pop` 里读 `(*head).next` 的那一步 unsafe，成立理由要想清楚再写。</small>
</details>

### 🟢 入门 · 有效的括号

**参考解析**: 目标是满足“最近打开的括号必须最先关闭”，正好是栈的后进先出——左括号压栈，右括号就看栈顶是不是它的另一半，最后栈空才算全部配对成功。

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
pub fn is_valid(s: &str) -> bool {
    let mut stack: Vec<char> = Vec::new();
    for c in s.chars() {
        match c {
            '(' | '[' | '{' => stack.push(c),
            ')' => {
                if stack.pop() != Some('(') {
                    return false;
                }
            }
            ']' => {
                if stack.pop() != Some('[') {
                    return false;
                }
            }
            '}' => {
                if stack.pop() != Some('{') {
                    return false;
                }
            }
            _ => return false, // 题目约定只含括号字符
        }
    }
    stack.is_empty()
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn cases() {
        assert!(is_valid("()[]{}"));
        assert!(is_valid("{[]}"));
        assert!(!is_valid("([)]"));
        assert!(!is_valid("(]"));
        assert!(!is_valid("("));
        assert!(!is_valid(")("));
        assert!(is_valid(""));
    }
}
```

### 🟡 进阶 · 手写迷你 RefCell（7 个测试）

**参考解析**： 把借用规则搬到运行时：一个计数表示借用状态（正数是共享借用个数、-1 是独占借用），发守卫前先查计数、冲突就 panic 或返回 Err，守卫 Drop 时再把计数改回去。值放在 UnsafeCell 里，而计数保证同一时刻不会出现别名的 &mut， 所以对外是稳妥的。

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
use std::cell::{Cell, UnsafeCell};
use std::ops::{Deref, DerefMut};

#[derive(Debug)]
pub struct BorrowError;

#[derive(Debug)]
pub struct BorrowMutError;

pub struct MyRefCell<T> {
    value: UnsafeCell<T>,
    borrowed: Cell<isize>,
}

impl<T> MyRefCell<T> {
    pub fn new(value: T) -> Self {
        MyRefCell {
            value: UnsafeCell::new(value),
            borrowed: Cell::new(0),
        }
    }

    pub fn borrow(&self) -> Ref<'_, T> {
        self.try_borrow().expect("already mutably borrowed")
    }

    pub fn try_borrow(&self) -> Result<Ref<'_, T>, BorrowError> {
        let flag = self.borrowed.get();
        if flag < 0 {
            return Err(BorrowError);
        }
        self.borrowed.set(flag + 1);
        Ok(Ref { cell: self })
    }

    pub fn borrow_mut(&self) -> RefMut<'_, T> {
        self.try_borrow_mut().expect("already borrowed")
    }

    pub fn try_borrow_mut(&self) -> Result<RefMut<'_, T>, BorrowMutError> {
        if self.borrowed.get() != 0 {
            return Err(BorrowMutError);
        }
        self.borrowed.set(-1);
        Ok(RefMut { cell: self })
    }

    pub fn into_inner(self) -> T {
        self.value.into_inner()
    }
}

pub struct Ref<'a, T> {
    cell: &'a MyRefCell<T>,
}

impl<T> Deref for Ref<'_, T> {
    type Target = T;
    fn deref(&self) -> &T {
        // 安全依据：flag >= 1 保证没有 &mut 存在，共享引用可以并存。
        unsafe { &*self.cell.value.get() }
    }
}

impl<T> Drop for Ref<'_, T> {
    fn drop(&mut self) {
        let flag = self.cell.borrowed.get();
        debug_assert!(flag > 0);
        self.cell.borrowed.set(flag - 1);
    }
}

pub struct RefMut<'a, T> {
    cell: &'a MyRefCell<T>,
}

impl<T> Deref for RefMut<'_, T> {
    type Target = T;
    fn deref(&self) -> &T {
        unsafe { &*self.cell.value.get() }
    }
}

impl<T> DerefMut for RefMut<'_, T> {
    fn deref_mut(&mut self) -> &mut T {
        // 安全依据：flag == -1 且只有本 guard 能置 -1，独占成立。
        unsafe { &mut *self.cell.value.get() }
    }
}

impl<T> Drop for RefMut<'_, T> {
    fn drop(&mut self) {
        debug_assert_eq!(self.cell.borrowed.get(), -1);
        self.cell.borrowed.set(0);
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn shared_borrows_coexist() {
        let cell = MyRefCell::new(vec![1, 2, 3]);
        let a = cell.borrow();
        let b = cell.borrow();
        assert_eq!(a.len(), 3);
        assert_eq!(b[0], 1);
    }

    #[test]
    fn borrow_mut_modifies_then_read() {
        let cell = MyRefCell::new(10);
        {
            let mut m = cell.borrow_mut();
            *m += 5;
        }
        assert_eq!(*cell.borrow(), 15);
    }

    #[test]
    #[should_panic]
    fn borrow_mut_while_shared_panics() {
        let cell = MyRefCell::new(1);
        let _a = cell.borrow();
        let _m = cell.borrow_mut();
    }

    #[test]
    #[should_panic]
    fn borrow_while_mut_panics() {
        let cell = MyRefCell::new(1);
        let _m = cell.borrow_mut();
        let _a = cell.borrow();
    }

    #[test]
    fn try_borrow_fails_during_mut_then_succeeds() {
        let cell = MyRefCell::new(1);
        {
            let _m = cell.borrow_mut();
            assert!(cell.try_borrow().is_err());
            assert!(cell.try_borrow_mut().is_err());
        }
        assert!(cell.try_borrow().is_ok());
        assert!(cell.try_borrow_mut().is_ok());
    }

    #[test]
    fn try_borrow_mut_fails_during_shared() {
        let cell = MyRefCell::new(1);
        let _a = cell.borrow();
        assert!(cell.try_borrow_mut().is_err());
        assert!(cell.try_borrow().is_ok()); // 共享借用仍可叠加
    }

    #[test]
    fn sequential_mut_borrows_and_into_inner() {
        let cell = MyRefCell::new(String::from("a"));
        cell.borrow_mut().push('b');
        cell.borrow_mut().push('c');
        assert_eq!(cell.into_inner(), "abc");
    }
}
```

### 🔴 挑战 · 手写迷你表达式求值器（5 个测试）

**参考解析**： 关键点是递归下降时用调用层级表达优先级：expr 管 + -、term 管 * / %、factor 管一元负号、atom 管数字、变量和括号子表达式，优先级天然成立，不用显式比较运算符权重。所有错误（语法错、未知变量、除零）都走 EvalError 返回，全程不 panic。

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
use std::collections::HashMap;

#[derive(Debug, PartialEq)]
pub enum EvalError {
    ParseError(String),
    UnknownVariable(String),
    DivisionByZero,
}

#[derive(Debug, Clone, PartialEq)]
enum Token {
    Num(i64),
    Ident(String),
    Plus,
    Minus,
    Star,
    Slash,
    Percent,
    LParen,
    RParen,
}

fn tokenize(input: &str) -> Result<Vec<Token>, EvalError> {
    let mut tokens = Vec::new();
    let mut chars = input.chars().peekable();
    while let Some(&c) = chars.peek() {
        match c {
            c if c.is_whitespace() => {
                chars.next();
            }
            '0'..='9' => {
                let mut n: i64 = 0;
                while let Some(&d) = chars.peek() {
                    if let Some(v) = d.to_digit(10) {
                        n = n * 10 + v as i64;
                        chars.next();
                    } else {
                        break;
                    }
                }
                tokens.push(Token::Num(n));
            }
            'a'..='z' | 'A'..='Z' | '_' => {
                let mut name = String::new();
                while let Some(&d) = chars.peek() {
                    if d.is_ascii_alphanumeric() || d == '_' {
                        name.push(d);
                        chars.next();
                    } else {
                        break;
                    }
                }
                tokens.push(Token::Ident(name));
            }
            '+' => {
                chars.next();
                tokens.push(Token::Plus);
            }
            '-' => {
                chars.next();
                tokens.push(Token::Minus);
            }
            '*' => {
                chars.next();
                tokens.push(Token::Star);
            }
            '/' => {
                chars.next();
                tokens.push(Token::Slash);
            }
            '%' => {
                chars.next();
                tokens.push(Token::Percent);
            }
            '(' => {
                chars.next();
                tokens.push(Token::LParen);
            }
            ')' => {
                chars.next();
                tokens.push(Token::RParen);
            }
            other => {
                return Err(EvalError::ParseError(format!("unexpected character '{other}'")));
            }
        }
    }
    Ok(tokens)
}

struct Parser<'a> {
    tokens: &'a [Token],
    pos: usize,
    vars: &'a HashMap<String, i64>,
}

impl<'a> Parser<'a> {
    fn peek(&self) -> Option<&Token> {
        self.tokens.get(self.pos)
    }

    fn next(&mut self) -> Option<Token> {
        let t = self.tokens.get(self.pos).cloned();
        if t.is_some() {
            self.pos += 1;
        }
        t
    }

    // expr := term (('+' | '-') term)*
    fn expr(&mut self) -> Result<i64, EvalError> {
        let mut value = self.term()?;
        loop {
            match self.peek() {
                Some(Token::Plus) => {
                    self.next();
                    value += self.term()?;
                }
                Some(Token::Minus) => {
                    self.next();
                    value -= self.term()?;
                }
                _ => break,
            }
        }
        Ok(value)
    }

    // term := factor (('*' | '/' | '%') factor)*
    fn term(&mut self) -> Result<i64, EvalError> {
        let mut value = self.factor()?;
        loop {
            match self.peek() {
                Some(Token::Star) => {
                    self.next();
                    value *= self.factor()?;
                }
                Some(Token::Slash) => {
                    self.next();
                    let rhs = self.factor()?;
                    if rhs == 0 {
                        return Err(EvalError::DivisionByZero);
                    }
                    value /= rhs;
                }
                Some(Token::Percent) => {
                    self.next();
                    let rhs = self.factor()?;
                    if rhs == 0 {
                        return Err(EvalError::DivisionByZero);
                    }
                    value %= rhs;
                }
                _ => break,
            }
        }
        Ok(value)
    }

    // factor := '-' factor | atom
    fn factor(&mut self) -> Result<i64, EvalError> {
        if matches!(self.peek(), Some(Token::Minus)) {
            self.next();
            Ok(-self.factor()?)
        } else {
            self.atom()
        }
    }

    // atom := Num | Ident | '(' expr ')'
    fn atom(&mut self) -> Result<i64, EvalError> {
        match self.next() {
            Some(Token::Num(n)) => Ok(n),
            Some(Token::Ident(name)) => self
                .vars
                .get(&name)
                .copied()
                .ok_or(EvalError::UnknownVariable(name)),
            Some(Token::LParen) => {
                let value = self.expr()?;
                match self.next() {
                    Some(Token::RParen) => Ok(value),
                    _ => Err(EvalError::ParseError("expected ')'".to_string())),
                }
            }
            other => Err(EvalError::ParseError(format!("unexpected token {other:?}"))),
        }
    }
}

pub fn eval(expr: &str, vars: &HashMap<String, i64>) -> Result<i64, EvalError> {
    let tokens = tokenize(expr)?;
    let mut parser = Parser {
        tokens: &tokens,
        pos: 0,
        vars,
    };
    let value = parser.expr()?;
    if parser.pos != tokens.len() {
        return Err(EvalError::ParseError("trailing characters".to_string()));
    }
    Ok(value)
}
```
