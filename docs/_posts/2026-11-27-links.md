### 🟢 入门 · 有效的括号 {#easy}

- 适合：理解字符串和 Vec
- 时间：约 10–15 分钟
- 题目：只用标准库，判断一个只由括号组成的字符串是否有效

```rust
/// s 只含 ()[]{} 六种字符。
/// 有效 = 每种括号都成对出现且嵌套顺序正确。
pub fn is_valid(s: &str) -> bool;
```

通过标准：

```rust
assert!(is_valid("()[]{}"));
assert!(is_valid("{[]}"));
assert!(!is_valid("([)]"));
assert!(!is_valid("(]"));
assert!(!is_valid("("));
assert!(!is_valid(")("));
assert!(is_valid(""));
```

<small>提示：用一个 Vec 当栈：遇到左括号压栈，遇到右括号就弹出栈顶看配不配对；最后栈空才算有效。注意空字符串是有效的。</small>
</details>

### 🟡 进阶 · 手写迷你 RefCell {#medium}

- 适合：学习内部可变性和运行时借用检查
- 时间：约 30–45 分钟
- 题目：只用标准库，手写一个迷你版 `RefCell`：编译期借用规则搬到运行时检查，冲突时 panic 或返回 `Err`

```rust
pub struct MyRefCell<T> { /* 你来定 */ }

impl<T> MyRefCell<T> {
    pub fn new(value: T) -> Self;
    /// 共享借用，可同时存在多个；已有独占借用时 panic。
    pub fn borrow(&self) -> Ref<'_, T>;
    /// 独占借用，同时只能有一个，且不能有共享借用；冲突时 panic。
    pub fn borrow_mut(&self) -> RefMut<'_, T>;
    /// 不 panic 的版本，冲突时返回 Err。
    pub fn try_borrow(&self) -> Result<Ref<'_, T>, BorrowError>;
    pub fn try_borrow_mut(&self) -> Result<RefMut<'_, T>, BorrowMutError>;
    pub fn into_inner(self) -> T;
}

// Ref 实现 Deref；RefMut 实现 Deref + DerefMut；
// 两个守卫 Drop 时都要把借用状态释放掉。
```

要求：
- 值存在 `UnsafeCell` 里；借用状态用一个计数表示：`0` 空闲、正数是共享借用个数、`-1` 是独占借用（状态本身可以用 `Cell<isize>` 存）。
- `borrow` 在独占借用存在时 panic；`borrow_mut` 在任何借用存在时 panic；`try_` 版本不 panic，返回 `Err`。
- 守卫是 RAII 的：`Ref` Drop 时计数减一，`RefMut` Drop 时状态清零；守卫还活着时借用就没释放。
- 内部可以 unsafe，但对外必须是 sound 的：只要安全代码按 API 用，就不能造出别名的 `&mut`。

通过标准：

```rust
// 1. 多个共享借用可以并存
let cell = MyRefCell::new(vec![1, 2, 3]);
let a = cell.borrow();
let b = cell.borrow();
assert_eq!(a.len(), 3);
assert_eq!(b[0], 1);

// 2. 独占借用改值，释放后能读到新值
let cell = MyRefCell::new(10);
{
    let mut m = cell.borrow_mut();
    *m += 5;
}
assert_eq!(*cell.borrow(), 15);

// 3. 冲突要 panic（各写一个 #[should_panic] 测试）：
//    - 有共享借用时 borrow_mut
//    - 有独占借用时 borrow

// 4. try_ 版本冲突时返回 Err，守卫 Drop 后恢复可用
let cell = MyRefCell::new(1);
{
    let _m = cell.borrow_mut();
    assert!(cell.try_borrow().is_err());
    assert!(cell.try_borrow_mut().is_err());
}
assert!(cell.try_borrow().is_ok());

// 5. 有共享借用时 try_borrow_mut 失败，但 try_borrow 仍可叠加
let cell = MyRefCell::new(1);
let _a = cell.borrow();
assert!(cell.try_borrow_mut().is_err());
assert!(cell.try_borrow().is_ok());

// 6. 连续两次独占借用 + into_inner
let cell = MyRefCell::new(String::from("a"));
cell.borrow_mut().push('b');
cell.borrow_mut().push('c');
assert_eq!(cell.into_inner(), "abc");
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：难点不在计数，在守卫的生命周期和 Deref：`Ref` 的 `deref` 要从 `UnsafeCell` 的裸指针造 `&T`，这一步 unsafe 的成立理由是“计数保证此刻没有 &mut”。另一个容易漏的点：`borrow()` 可以用 `try_borrow().expect(...)` 实现，panic 消息写清楚是哪种冲突。</small>
</details>

### 🔴 挑战 · 手写迷你表达式求值器 {#hard}

- 适合：练习递归下降解析和错误处理
- 时间：约 45–60 分钟
- 题目：只用标准库，写一个整数表达式求值器，支持变量

```rust
use std::collections::HashMap;

#[derive(Debug, PartialEq)]
pub enum EvalError {
    ParseError(String),          // 语法错误，带一句说明
    UnknownVariable(String),     // 用了没给值的变量
    DivisionByZero,              // 除以零（/ 和 % 都算）
}

/// 计算 expr 的值；变量从 vars 里查。
pub fn eval(expr: &str, vars: &HashMap<String, i64>) -> Result<i64, EvalError>;
```

要求：
- 支持 `+ - * / %` 和括号，`* / %` 优先级高于 `+ -`，同级左结合；支持一元负号（`-5`、`2 * -3`、`-(1 + 2)` 都要对）。
- 整数除法向零截断（Rust 的 `/` 本来就是），除以零返回 `DivisionByZero`，不许 panic。
- 标识符由字母、数字、下划线组成（首字符不为数字）；数字、标识符、运算符之间的空白可有可无。
- 语法错（空字符串、括号不配对、末尾多余字符、运算符后面缺操作数）一律返回 `ParseError`，不许 panic。

通过标准：

```rust
let no_vars = HashMap::new();
assert_eq!(eval("1 + 2 * 3", &no_vars), Ok(7));
assert_eq!(eval("(1 + 2) * 3", &no_vars), Ok(9));
assert_eq!(eval("10 - 2 - 3", &no_vars), Ok(5));
assert_eq!(eval("10 / 3", &no_vars), Ok(3));
assert_eq!(eval("10 % 3", &no_vars), Ok(1));
assert_eq!(eval("-5 + 3", &no_vars), Ok(-2));
assert_eq!(eval("2 * -3", &no_vars), Ok(-6));

let mut vars = HashMap::new();
vars.insert("x".to_string(), 3);
vars.insert("y".to_string(), 4);
assert_eq!(eval("x * 2 + y", &vars), Ok(10));

assert_eq!(eval("1 / 0", &no_vars), Err(EvalError::DivisionByZero));
assert_eq!(eval("foo + 1", &no_vars), Err(EvalError::UnknownVariable("foo".to_string())));
// 以下只需断言是 ParseError（用 matches!）：
assert!(matches!(eval("1 +", &no_vars), Err(EvalError::ParseError(_))));
assert!(matches!(eval("(1 + 2", &no_vars), Err(EvalError::ParseError(_))));
assert!(matches!(eval("", &no_vars), Err(EvalError::ParseError(_))));
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：经典结构是先分词（tokenize 成数字 / 标识符 / 运算符 / 括号），再递归下降分层：expr 管 `+ -`、term 管 `* / %`、factor 管一元负号、atom 管数字 / 变量 / 括号子表达式。优先级靠这个调用层级实现，不用显式比较运算符权重。变量在 atom 层查 HashMap。</small>
</details>

### 🟢 入门 · 两数之和

<summary>点击展开参考代码</summary>

```rust
use std::collections::HashMap;

fn two_sum(nums: &[i32], target: i32) -> Option<(usize, usize)> {
    let mut seen: HashMap<i32, usize> = HashMap::new();
    for (i, &n) in nums.iter().enumerate() {
        if let Some(&j) = seen.get(&(target - n)) {
            return Some((j, i));
        }
        seen.insert(n, i);
    }
    None
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn two_sum_works() {
        assert_eq!(two_sum(&[2, 7, 11, 15], 9), Some((0, 1)));
        assert_eq!(two_sum(&[3, 2, 4], 6), Some((1, 2)));
        assert_eq!(two_sum(&[3, 3], 6), Some((0, 1)));
        assert_eq!(two_sum(&[1, 2, 3], 7), None);
        assert_eq!(two_sum(&[], 0), None);
    }
}
```

### 🟡 进阶 · 手写迷你 async 执行器（5 个测试）

<details markdown="1">
<summary>点击展开参考代码</summary>

```rust
use std::future::Future;
use std::pin::Pin;
use std::sync::{Arc, Mutex};
use std::task::{Context, Poll, Wake, Waker};
use std::thread;
use std::time::Duration;

// ---------- block_on ----------

struct ThreadWaker(thread::Thread);

impl Wake for ThreadWaker {
    fn wake(self: Arc<Self>) {
        self.0.unpark();
    }
    fn wake_by_ref(self: &Arc<Self>) {
        self.0.unpark();
    }
}

pub fn block_on<F: Future>(fut: F) -> F::Output {
    let waker = Waker::from(Arc::new(ThreadWaker(thread::current())));
    let mut cx = Context::from_waker(&waker);
    let mut fut = Box::pin(fut);
    loop {
        match fut.as_mut().poll(&mut cx) {
            Poll::Ready(v) => return v,
            Poll::Pending => thread::park(),
        }
    }
}

// ---------- TimerFuture ----------

struct SharedState {
    completed: bool,
    waker: Option<Waker>,
}

pub struct TimerFuture {
    shared: Arc<Mutex<SharedState>>,
}

impl TimerFuture {
    pub fn new(duration: Duration) -> Self {
        let shared = Arc::new(Mutex::new(SharedState {
            completed: false,
            waker: None,
        }));
        let thread_shared = shared.clone();
        thread::spawn(move || {
            thread::sleep(duration);
            let mut state = thread_shared.lock().unwrap();
            state.completed = true;
            if let Some(waker) = state.waker.take() {
                waker.wake();
            }
        });
        TimerFuture { shared }
    }
}

impl Future for TimerFuture {
    type Output = ();

    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<()> {
        let mut state = self.shared.lock().unwrap();
        if state.completed {
            Poll::Ready(())
        } else {
            state.waker = Some(cx.waker().clone());
            Poll::Pending
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::time::Instant;

    #[test]
    fn ready_future_returns_immediately() {
        assert_eq!(block_on(async { 40 + 2 }), 42);
    }

    #[test]
    fn timer_completes_after_duration() {
        let start = Instant::now();
        block_on(TimerFuture::new(Duration::from_millis(50)));
        let elapsed = start.elapsed();
        assert!(elapsed >= Duration::from_millis(40), "elapsed: {elapsed:?}");
        assert!(elapsed < Duration::from_secs(5));
    }

    #[test]
    fn zero_duration_timer_still_completes() {
        block_on(TimerFuture::new(Duration::ZERO));
    }

    #[test]
    fn sequential_timers_add_up() {
        let start = Instant::now();
        block_on(async {
            TimerFuture::new(Duration::from_millis(30)).await;
            TimerFuture::new(Duration::from_millis(30)).await;
        });
        assert!(start.elapsed() >= Duration::from_millis(50));
    }

    #[test]
    fn self_waking_future_is_polled_again() {
        struct WakeOnce {
            woke: bool,
        }
        impl Future for WakeOnce {
            type Output = i32;
            fn poll(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<i32> {
                if self.woke {
                    Poll::Ready(7)
                } else {
                    self.woke = true;
                    cx.waker().wake_by_ref();
                    Poll::Pending
                }
            }
        }
        assert_eq!(block_on(WakeOnce { woke: false }), 7);
    }
}
```

### 🔴 挑战 · 手写 O(1) 的 LRU 缓存（5 个测试）

<details markdown="1">
<summary>点击展开参考代码</summary>

**参考解析**: 使用数组和下标实现（双向）链表。

```rust
use std::collections::HashMap;
use std::hash::Hash;

struct Node<K, V> {
    key: K,
    value: V,
    prev: Option<usize>,
    next: Option<usize>,
}

pub struct LruCache<K, V> {
    capacity: usize,
    map: HashMap<K, usize>,
    nodes: Vec<Node<K, V>>,
    free: Vec<usize>,
    head: Option<usize>, // 最近使用
    tail: Option<usize>, // 最久未使用
}

impl<K: Eq + Hash + Clone, V> LruCache<K, V> {
    pub fn new(capacity: usize) -> Self {
        LruCache {
            capacity,
            map: HashMap::new(),
            nodes: Vec::new(),
            free: Vec::new(),
            head: None,
            tail: None,
        }
    }

    pub fn len(&self) -> usize {
        self.map.len()
    }

    pub fn is_empty(&self) -> bool {
        self.map.is_empty()
    }

    fn detach(&mut self, idx: usize) {
        let prev = self.nodes[idx].prev;
        let next = self.nodes[idx].next;
        match prev {
            Some(p) => self.nodes[p].next = next,
            None => self.head = next,
        }
        match next {
            Some(n) => self.nodes[n].prev = prev,
            None => self.tail = prev,
        }
        self.nodes[idx].prev = None;
        self.nodes[idx].next = None;
    }

    fn push_front(&mut self, idx: usize) {
        self.nodes[idx].prev = None;
        self.nodes[idx].next = self.head;
        if let Some(h) = self.head {
            self.nodes[h].prev = Some(idx);
        }
        self.head = Some(idx);
        if self.tail.is_none() {
            self.tail = Some(idx);
        }
    }

    fn move_to_front(&mut self, idx: usize) {
        if self.head != Some(idx) {
            self.detach(idx);
            self.push_front(idx);
        }
    }

    pub fn get(&mut self, key: &K) -> Option<&V> {
        let idx = *self.map.get(key)?;
        self.move_to_front(idx);
        Some(&self.nodes[idx].value)
    }

    pub fn put(&mut self, key: K, value: V) {
        if self.capacity == 0 {
            return;
        }
        if let Some(&idx) = self.map.get(&key) {
            self.nodes[idx].value = value;
            self.move_to_front(idx);
            return;
        }
        if self.map.len() >= self.capacity {
            let tail = self.tail.expect("non-empty cache has a tail");
            self.detach(tail);
            let old_key = self.nodes[tail].key.clone();
            self.map.remove(&old_key);
            self.free.push(tail);
        }
        let idx = if let Some(i) = self.free.pop() {
            self.nodes[i] = Node {
                key: key.clone(),
                value,
                prev: None,
                next: None,
            };
            i
        } else {
            self.nodes.push(Node {
                key: key.clone(),
                value,
                prev: None,
                next: None,
            });
            self.nodes.len() - 1
        };
        self.map.insert(key, idx);
        self.push_front(idx);
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn basic_put_get_and_eviction() {
        let mut cache = LruCache::new(2);
        cache.put(1, "a");
        cache.put(2, "b");
        assert_eq!(cache.get(&1), Some(&"a")); // 1 变最近使用
        cache.put(3, "c"); // 淘汰 2
        assert_eq!(cache.get(&2), None);
        assert_eq!(cache.get(&3), Some(&"c"));
        assert_eq!(cache.len(), 2);
    }

    #[test]

        assert_eq!(cache.get(&1), Some(&"a2"));
    }

    #[test]
    fn zero_capacity_stores_nothing() {
        let mut cache = LruCache::<i32, i32>::new(0);

    }

    }
```
