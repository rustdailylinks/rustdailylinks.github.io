### 🟢 入门 · 两数之和 {#easy}

- 适合：练习 HashMap
- 时间：约 15 分钟
- 题目：在切片里找两个数，它们的和等于 `target`，返回它们的下标（小的在前）；保证有且仅有一组解时返回它，没有返回 `None`，同一个元素不能用两次：

```rust
use std::collections::HashMap;

fn two_sum(nums: &[i32], target: i32) -> Option<(usize, usize)>
```

通过标准：

```rust
assert_eq!(two_sum(&[2, 7, 11, 15], 9), Some((0, 1)));
assert_eq!(two_sum(&[3, 2, 4], 6), Some((1, 2)));
assert_eq!(two_sum(&[3, 3], 6), Some((0, 1)));
assert_eq!(two_sum(&[1, 2, 3], 7), None);
assert_eq!(two_sum(&[], 0), None);
```

### 🟡 进阶 · 手写迷你 async 执行器 {#medium}

- 适合：理解 async / await 底层原理
- 时间：约 30–45 分钟
- 题目：只用标准库，手写一个迷你执行器和一个定时器 future，理解 `Future`、`Waker` 和执行器之间的合同：

```rust
use std::future::Future;
use std::time::Duration;

/// 在当前线程上把一个 future 跑到完成；Pending 时挂起线程，被唤醒后再 poll。
pub fn block_on<F: Future>(fut: F) -> F::Output;

/// 一个“等够时长才完成”的 future：new 时起一个线程计时，
/// 到点后把自己标为完成并唤醒最后登记的 Waker。
pub struct TimerFuture { /* 你来定 */ }

impl TimerFuture {
    pub fn new(duration: Duration) -> Self;
}

impl Future for TimerFuture {
    type Output = ();
}
```

要求：
- `block_on` 不能忙等空转：`Pending` 后用 `std::thread::park` 挂起，靠 `Waker` 的 `unpark` 唤醒（用 `std::task::Wake` 给当前线程造一个 Waker）。
- `TimerFuture` 每次 `poll` 都要登记**最新**的 `Waker`（执行器可能换 Waker，存旧的会唤醒不到）。
- 竞态要处理：计时线程可能在第一次 `poll` 之前就结束，此时 `poll` 要直接返回 `Ready`；计时线程到点时如果已有 Waker 登记，先标记完成再唤醒，顺序不能反。

通过标准：

```rust
use std::time::Instant;

// 1. 立即完成的 future 直接返回值
assert_eq!(block_on(async { 40 + 2 }), 42);

// 2. TimerFuture 到点才完成
let start = Instant::now();
block_on(TimerFuture::new(Duration::from_millis(50)));
let elapsed = start.elapsed();
assert!(elapsed >= Duration::from_millis(40));
assert!(elapsed < Duration::from_secs(5));

// 3. 0 时长的计时器也不能死锁（线程先于 poll 结束的竞态）
block_on(TimerFuture::new(Duration::ZERO));

// 4. 两个计时器顺序 await，总时长叠加
let start = Instant::now();
block_on(async {
    TimerFuture::new(Duration::from_millis(30)).await;
    TimerFuture::new(Duration::from_millis(30)).await;
});
assert!(start.elapsed() >= Duration::from_millis(50));

// 5. 自己唤醒自己的 future 会被再次 poll
struct WakeOnce { woke: bool }
impl Future for WakeOnce {
    type Output = i32;
    fn poll(mut self: std::pin::Pin<&mut Self>, cx: &mut std::task::Context<'_>)
        -> std::task::Poll<i32>
    {
        if self.woke {
            std::task::Poll::Ready(7)
        } else {
            self.woke = true;
            cx.waker().wake_by_ref();
            std::task::Poll::Pending
        }
    }
}
assert_eq!(block_on(WakeOnce { woke: false }), 7);
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：Waker 用 `Arc` 包一个实现 `std::task::Wake` 的小结构，里面存 `thread::current()`，`wake` 时 `unpark`；注意 `unpark` 先于 `park` 发生时，那次 `park` 会立即返回，不会丢唤醒。`TimerFuture` 的共享状态用 `Arc<Mutex<…>>`，里面放 `completed: bool` 和 `waker: Option<Waker>`；计时线程醒来先上锁改状态、取出 waker 再唤醒，`poll` 也是先查 `completed` 再登记 waker，两个方向的竞态都靠这把锁和这个顺序兜住。</small>
</details>

### 🔴 挑战 · 手写 O(1) 的 LRU 缓存 {#hard}

- 适合：练习数据结构设计、跟借用检查器博弈
- 时间：约 45–60 分钟
- 题目：只用标准库，手写一个泛型 LRU 缓存，`get` 和 `put` 都必须是 O(1)：

```rust
pub struct LruCache<K, V> { /* 你来定 */ }

impl<K: Eq + std::hash::Hash + Clone, V> LruCache<K, V> {
    /// capacity 为 0 时什么都存不下：put 无效，get 永远返回 None。
    pub fn new(capacity: usize) -> Self;
    /// 命中返回值的引用，并把这个 key 标记为最近使用；未命中返回 None。
    pub fn get(&mut self, key: &K) -> Option<&V>;
    /// 插入新条目或更新已有条目（更新也要刷新顺序）；
    /// 超出容量时淘汰最久未使用的条目。
    pub fn put(&mut self, key: K, value: V);
    pub fn len(&self) -> usize;
}
```

要求：
- `get` / `put` 均摊 O(1)。难点在这：`HashMap` 能 O(1) 按 key 找到条目，但“把条目挪到最近使用端、淘汰最久未使用”还要一条 O(1) 的顺序链。
- 标准库的 `LinkedList` 给不了 O(1) 的按节点删除/移动（拿不到节点句柄），常见解法是索引式链表：`Vec` 当节点池，每个节点存 `prev` / `next` 下标，`HashMap<K, usize>` 存 key 到下标，再用一个空闲下标列表回收淘汰节点的坑位。其他能做到 O(1) 的方案也可以。
- 更新已有 key：只改值并刷新顺序，`len` 不变，也不触发淘汰。

通过标准：

```rust
// 1. 基本读写 + 淘汰最久未使用
let mut cache = LruCache::new(2);
cache.put(1, "a");
cache.put(2, "b");
assert_eq!(cache.get(&1), Some(&"a")); // 1 变最近使用
cache.put(3, "c");                       // 淘汰 2
assert_eq!(cache.get(&2), None);
assert_eq!(cache.get(&3), Some(&"c"));
assert_eq!(cache.len(), 2);

// 2. 更新已有 key：值变、顺序刷新、len 不变
cache.put(1, "a2");
assert_eq!(cache.len(), 2);
cache.put(4, "d"); // 淘汰 3（1 刚被刷新）
assert_eq!(cache.get(&3), None);
assert_eq!(cache.get(&1), Some(&"a2"));

// 3. capacity 为 0：什么都存不下
let mut empty = LruCache::<i32, i32>::new(0);
empty.put(1, 1);
assert_eq!(empty.get(&1), None);
assert_eq!(empty.len(), 0);

// 4. capacity 为 1：新来的立刻淘汰旧的
let mut one = LruCache::new(1);
one.put("x", 1);
one.put("y", 2);
assert_eq!(one.get(&"x"), None);
assert_eq!(one.get(&"y"), Some(&2));
```

<details markdown="1">
<summary>点击查看提示</summary>
<small>提示：先把四个基本操作拆出来想清楚：detach（把节点从链上摘下）、push_front（把节点挂到头部）、move_to_front = detach + push_front、淘汰 = detach(tail) 再从 HashMap 删除。head 是最近使用端，tail 是最久未使用端；只有一个节点时它同时是 head 和 tail，detach 后两个都要清空。还有一个容易卡住的点：`get` 要返回 `&V` 又要改链顺序，所以它收 `&mut self`。</small>
</details>

```rust
// 合并两个已排序切片（2026-11-24）
fn merge_sorted(a: &[i32], b: &[i32]) -> Vec<i32> {
    let mut out = Vec::with_capacity(a.len() + b.len());
    let (mut i, mut j) = (0, 0);
    while i < a.len() && j < b.len() {
        if a[i] <= b[j] {
            out.push(a[i]);
            i += 1;
        } else {
            out.push(b[j]);
            j += 1;
        }
    }
    out.extend_from_slice(&a[i..]);
    out.extend_from_slice(&b[j..]);
    out
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn merge_works() {
        assert_eq!(merge_sorted(&[1, 3, 5], &[2, 4, 6]), vec![1, 2, 3, 4, 5, 6]);
        assert_eq!(merge_sorted(&[], &[1]), vec![1]);
        assert_eq!(merge_sorted(&[1, 2], &[]), vec![1, 2]);
        assert_eq!(merge_sorted(&[1, 1, 3], &[1, 2]), vec![1, 1, 1, 2, 3]);
        assert_eq!(merge_sorted(&[], &[]), Vec::<i32>::new());
    }
}
```

### 🟡 进阶 · 手写迷你线程池 ThreadPool（附5个测试）

<details markdown="1">
<summary>点击查看代码</summary>

```rust
use std::sync::{mpsc, Arc, Mutex};
use std::thread;

type Job = Box<dyn FnOnce() + Send + 'static>;

pub struct ThreadPool {
    sender: Option<mpsc::Sender<Job>>,
    workers: Vec<Worker>,
}

impl ThreadPool {
    pub fn new(size: usize) -> Self {
        assert!(size > 0, "ThreadPool size must be at least 1");
        let (sender, receiver) = mpsc::channel::<Job>();
        let receiver = Arc::new(Mutex::new(receiver));
        let mut workers = Vec::with_capacity(size);
        for _ in 0..size {
            workers.push(Worker::new(Arc::clone(&receiver)));
        }
        ThreadPool {
            sender: Some(sender),
            workers,
        }
    }

    pub fn execute<F>(&self, f: F)
    where
        F: FnOnce() + Send + 'static,
    {
        self.sender
            .as_ref()
            .expect("pool is being dropped")
            .send(Box::new(f))
            .expect("all workers are gone");
    }
}

impl Drop for ThreadPool {
    fn drop(&mut self) {
        // 先关通道：线程把队列里剩余任务做完，recv 收到 Err 后退出。
        drop(self.sender.take());
        for worker in &mut self.workers {
            if let Some(handle) = worker.handle.take() {
                let _ = handle.join();
            }
        }
    }
}

struct Worker {
    handle: Option<thread::JoinHandle<()>>,
}

impl Worker {
    fn new(receiver: Arc<Mutex<mpsc::Receiver<Job>>>) -> Self {
        let handle = thread::spawn(move || loop {
            // 锁只在 recv 期间持有，拿到任务立刻放锁再执行。
            let job = {
                let guard = receiver.lock().unwrap();
                guard.recv()
            };
            match job {
                Ok(job) => job(),
                Err(_) => break, // 通道关闭且已排空
            }
        });
        Worker {
            handle: Some(handle),
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::sync::atomic::{AtomicUsize, Ordering};
    use std::time::Duration;

    #[test]
    #[should_panic]
    fn zero_size_panics() {
        let _ = ThreadPool::new(0);
    }

    #[test]
    fn execute_runs_the_job() {
        let pool = ThreadPool::new(2);
        let (tx, rx) = mpsc::channel();
        pool.execute(move || {
            tx.send(42).unwrap();
        });
        assert_eq!(rx.recv().unwrap(), 42);
    }

    #[test]
    fn jobs_run_on_worker_threads() {
        let pool = ThreadPool::new(1);
        let main_id = thread::current().id();
        let (tx, rx) = mpsc::channel();
        pool.execute(move || {
            tx.send(thread::current().id()).unwrap();
        });
        assert_ne!(rx.recv().unwrap(), main_id);
    }

    #[test]
    fn drop_waits_for_queued_jobs() {
        let counter = Arc::new(AtomicUsize::new(0));
        {
            let pool = ThreadPool::new(4);
            for _ in 0..20 {
                let c = Arc::clone(&counter);
                pool.execute(move || {
                    thread::sleep(Duration::from_millis(5));
                    c.fetch_add(1, Ordering::SeqCst);
                });
            }
        } // pool 在这里 drop，必须等 20 个任务全做完
        assert_eq!(counter.load(Ordering::SeqCst), 20);
    }

    #[test]
    fn many_jobs_all_complete() {
        let counter = Arc::new(AtomicUsize::new(0));
        let pool = ThreadPool::new(4);
        for _ in 0..100 {
            let c = Arc::clone(&counter);
            pool.execute(move || {
                c.fetch_add(1, Ordering::SeqCst);
            });
        }
        drop(pool);
        assert_eq!(counter.load(Ordering::SeqCst), 100);
    }
}
```

### 🔴 挑战 · 手写迷你 MyVec<T>（附5个测试）

<details markdown="1">
<summary>点击查看代码</summary>

```rust
// 只用标准库；ZST（零大小类型）不作要求。

use std::alloc::{alloc, dealloc, handle_alloc_error, realloc, Layout};
use std::ops::{Deref, DerefMut};
use std::ptr::{self, NonNull};

pub struct MyVec<T> {
    ptr: NonNull<T>,
    len: usize,
    cap: usize,
}

impl<T> MyVec<T> {
    pub fn new() -> Self {
        Self {
            ptr: NonNull::dangling(),
            len: 0,
            cap: 0,
        }
    }

    pub fn len(&self) -> usize {
        self.len
    }

    pub fn is_empty(&self) -> bool {
        self.len == 0
    }

    pub fn capacity(&self) -> usize {
        self.cap
    }

    pub fn push(&mut self, value: T) {
        if self.len == self.cap {
            self.grow();
        }
        unsafe {
            ptr::write(self.ptr.as_ptr().add(self.len), value);
        }
        self.len += 1;
    }

    pub fn pop(&mut self) -> Option<T> {
        if self.len == 0 {
            return None;
        }
        self.len -= 1;
        unsafe { Some(ptr::read(self.ptr.as_ptr().add(self.len))) }
    }

    pub fn get(&self, index: usize) -> Option<&T> {
        if index < self.len {
            unsafe { Some(&*self.ptr.as_ptr().add(index)) }
        } else {
            None
        }
    }

    pub fn get_mut(&mut self, index: usize) -> Option<&mut T> {
        if index < self.len {
            unsafe { Some(&mut *self.ptr.as_ptr().add(index)) }
        } else {
            None
        }
    }

    fn grow(&mut self) {
        let new_cap = if self.cap == 0 { 4 } else { self.cap * 2 };
        let new_layout = Layout::array::<T>(new_cap).expect("capacity overflow");
        let raw = unsafe {
            if self.cap == 0 {
                alloc(new_layout)
            } else {
                let old_layout = Layout::array::<T>(self.cap).expect("capacity overflow");
                realloc(
                    self.ptr.as_ptr() as *mut u8,
                    old_layout,
                    new_layout.size(),
                )
            }
        };
        self.ptr = NonNull::new(raw as *mut T)
            .unwrap_or_else(|| handle_alloc_error(new_layout));
        self.cap = new_cap;
    }
}

impl<T> Deref for MyVec<T> {
    type Target = [T];
    fn deref(&self) -> &[T] {
        unsafe { std::slice::from_raw_parts(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> DerefMut for MyVec<T> {
    fn deref_mut(&mut self) -> &mut [T] {
        unsafe { std::slice::from_raw_parts_mut(self.ptr.as_ptr(), self.len) }
    }
}

impl<T> Drop for MyVec<T> {
    fn drop(&mut self) {
        unsafe {
            for i in 0..self.len {
                ptr::drop_in_place(self.ptr.as_ptr().add(i));
            }
            if self.cap != 0 {
                dealloc(
                    self.ptr.as_ptr() as *mut u8,
                    Layout::array::<T>(self.cap).expect("capacity overflow"),
                );
            }
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::cell::Cell;
    use std::rc::Rc;

    #[test]
    fn push_pop_and_len() {
        let mut v = MyVec::new();
        assert!(v.is_empty());
        assert_eq!(v.pop(), None);
        v.push(1);
        v.push(2);
        v.push(3);
        assert_eq!(v.len(), 3);
        assert_eq!(v.pop(), Some(3));
        assert_eq!(v.pop(), Some(2));
        assert_eq!(v.pop(), Some(1));
        assert_eq!(v.pop(), None);
    }

    #[test]

        let mut v = MyVec::new();
        for i in 0..100 {
            v.push(i);
        }
        assert_eq!(v.len(), 100);
        assert!(v.capacity() >= 100);
        for i in 0..100 {
            assert_eq!(v.get(i), Some(&i));
        }
        assert_eq!(v.get(100), None);
    }

    #[test]
    fn index_and_iter_via_deref() {
        let mut v = MyVec::new();
        v.push(10);
        v.push(20);
        v.push(30);
        assert_eq!(v[1], 20);
        assert_eq!(v.iter().sum::<i32>(), 60);
        v[0] = 99;
        assert_eq!(v[0], 99);
        *v.get_mut(2).unwrap() = 7;
        assert_eq!(v[2], 7);
    }

    #[test]
    fn drop_runs_for_all_elements() {
        struct Counted(Rc<Cell<usize>>);
        impl Drop for Counted {
            fn drop(&mut self) {
                self.0.set(self.0.get() + 1);
            }
        }
        let counter = Rc::new(Cell::new(0));
        {
            let mut v = MyVec::new();
            v.push(Counted(counter.clone()));

        assert_eq!(counter.get(), 3);
    }

        v.push(String::from("hello"));
        v.push(String::from("rust"));
        assert_eq!(v.len(), 2);
        assert_eq!(v[0], "hello");
        assert_eq!(v.pop().unwrap(), "rust");
    }
}
```
